# iele756-region-1

Este proyecto busca hacer un analisis de datos sociodemograficos y de salud dentro de la region de tarapacá, en donde se utilizaron bases de datos como el censo, ENO y GRD.
Todo esto con la finalidad de hacer un analisis en cuanto a la distribucion entre poblacion nacional y extranjera que vive en la region y los distintos reportes de salud, de los cuales se quiso extraer un top de enfermedades y atenciones dentro de hospitales de la región.
